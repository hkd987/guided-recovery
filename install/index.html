Install Guided Recovery OS

Flash the pod's operating system straight from this page over USB. You don't need any tools installed. Use desktop Chrome or Edge.

1. Install on the pod

  1. Build the pod from the parts list and wiring guide. It must be a Heltec V3 board; a V4 needs a different pin map.
  2. Put the magnet on (disarmed). Unplug the 2S battery, then connect the board with a USB-C data cable.
  3. Click Install, pick the board's serial port, and accept the erase prompt on a first install.
This browser can't flash over USB. Use desktop Chrome or Edge. Open this page over https to install.

2. Check it on the bench

  1. After installing, choose Logs & console in the installer's menu, or use any serial terminal at 115200 baud.
  2. Stand the pod upright with the magnet on, and type selftest. It checks every sensor, the GPS, battery, log space and radio, and moves each winch 25 mm.
  3. Fix anything it reports. It names the setting to change, for example set winch.encL -1 then save.
  4. Run log erase once, then zero with the brake lines slack.

Before any flight, fly the bench hardware-in-the-loop test (gate 4) and drop tests, as described in the build guide.

Optional: ground receiver

A second Heltec V3 with nothing attached shows the pod's flight phase, height and position over LoRa.

The pod never connects to or fires any pyro channel. Fly under your club's rules and NAR/Tripoli codes. Set your radio band with set radio.mhz 868 outside the US.
